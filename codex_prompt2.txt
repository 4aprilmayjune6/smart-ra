당신은 감사테크 시스템의 아키텍처 리뷰어입니다. 현재 디렉터리의 RFP_v1.0_audit-risk-platform.md (내부 버전 v1.2)를 읽으세요. 1차 검토(codex_review.txt, 총평 [조건부 적절]) 반영 후, 이번 v1.2에서 **구현·제공 방식을 MCP(Model Context Protocol) 서버 기반으로 개정**했습니다. 발주사는 기존에 K-IFRS 검색 등 MCP 도구 생태계를 보유하고 있어 MCP 제공이 확정 요구사항입니다.

이번 검토는 **MCP 개정분에 집중**하세요 (1차에서 이미 지적·반영된 사항 반복 금지):

- 4.6장 SFR-601~607, 5장 NFR-MCP-01~04, IR-06
- 8.3.7 (왜 MCP인가 — REST/웹콘솔과 서비스 계층 공유)
- 부록 D 도구·리소스·프롬프트 카탈로그(15개 도구)
- 12장 8항 MCP 적합성 검수
